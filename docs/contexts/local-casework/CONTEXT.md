# 本机办案工具

帮助律师在本机完成材料文字化、微信录屏取证和证据整理。其产物是待律师核实的办案辅助材料，不直接形成 OA 事实或审批结论。

## Language

**材料转换**:
把图片、PDF、Office 文件或音视频转换为便于检索和继续处理的文字或文档。
_Avoid_: 证据认定

**微信录屏取证**:
从微信聊天录屏中提取并组织可供律师复核的画面、文字索引和取证材料。
_Avoid_: 微信聊天事实确认

**证据整理**:
根据现有材料生成材料清单、文本汇总和时间线初稿的辅助过程。
_Avoid_: 证据审查结论、事实认定

**识别结果**:
通过 OCR 或语音转写得到、尚未由律师核实的文本。
_Avoid_: 已确认事实、原始证据

**案件输入包**:
把原始材料索引和派生整理结果组合起来，供后续案件分析流程读取的交接材料。
_Avoid_: 案件结论、OA 案件
