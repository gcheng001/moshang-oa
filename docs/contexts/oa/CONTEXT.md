# OA 业务

管理律所既有 OA 中的案件、立案审批和文书。该领域拥有所有改变 OA 案件状态的业务规则。

## Language

**案件**:
律所接受委托后在 OA 中登记并持续管理的法律事务，具有类型、规范案由或罪名、当事人、承办律师、收费约定和生命周期状态。

**案件列表**:
用户查询、筛选、查看案件详情和下载案件文书的工作入口。
_Avoid_: 案件看板、案件审批

**立案**:
承办律师向 OA 提交新案件信息，等待律所内部确认其可以进入正式办理状态。
_Avoid_: 建档、创建案件

**立案审批**:
审批人对待审案件作出通过或驳回决定的业务关口，包括资料、案由、利冲、重复立案和收费审查。
_Avoid_: 审核、检查

**对方当事人**:
民事、行政等存在相对方案件中的对立当事人；刑事案件没有该必填对象，立案审批不得因未填写对方当事人而阻断。
_Avoid_: 刑事案件必填对方、所有案件相对方

**刑事案件**:
以犯罪追诉、辩护或刑事法律援助为内容的案件，通常以规范罪名表明其性质；登记在公益法律等业务大类下不改变其刑事属性。
_Avoid_: 仅按业务大类判断刑事案件

**OA 账号**:
律师在摩尚 OA 中用于确认个人身份和业务权限的登录身份；一个人使用自己的账号，不与其他人共享。
_Avoid_: API Key、设备、审批账号

**审批账号**:
具有立案审批权限的 OA 登录身份；同一律所可以有多个审批账号，每个账号独立承担其自动审批授权和审计责任。
_Avoid_: 设备、审批人姓名

**审批权限**:
OA 授予某个账号查看全所待审案件并作出立案审批决定的业务能力，以账号实际权限为准，不由姓名或职位推定。
_Avoid_: 合伙人身份、案件查看权限、自动审批开关

**自动驳回**:
系统因一个或多个业务异常直接驳回立案申请，并在审批意见中逐条写明全部补正理由；补正后重新提交视为新的审批批次。
_Avoid_: 技术故障驳回、含糊驳回、第三次转人工

**业务异常**:
OA 已成功读取且能够确定违反立案审批规则的资料缺失、系统选项不合法、收费或利冲问题；它会触发自动驳回。
_Avoid_: 网络失败、OA 接口失败、字段无法读取

**技术异常**:
网络、OA 接口、登录或字段读取失败导致系统无法可靠作出业务判断的状态；案件保持待审并在下一轮重试，连续三轮异常时可通知审批人。
_Avoid_: 业务异常、自动驳回理由

**审批批次**:
一件立案申请从进入立案待审到通过、驳回或状态改变的一次处理过程；驳回补正后再次提交形成新的批次。
_Avoid_: 案号、驳回指纹

**审批值守**:
在审批人不持续打开主窗口时仍监测待审案件的持续工作状态；自动审批开关开启期间全天运行，登录、租约或网络异常时停止自动写入。
_Avoid_: 审批页面、定时提醒

**审批轮询**:
审批值守每三分钟查询一次新待审案件；首次发现后等待两分钟并重新读取，查询失败时不得执行自动写入。
_Avoid_: 实时推送、每分钟续租心跳

**自动审批开关**:
由当前审批账号显式开启或关闭自动写入权限的控制；默认关闭，不同账号之间不共享开关状态，切换账号后不得继承原账号的自动审批授权。
_Avoid_: 登录状态、开机自启、审批值守状态

**主要审批主机**:
日常持续运行自动审批的 Windows 电脑；Mac 端用于查看、配置和在主要主机不可用时人工接管。
_Avoid_: 多台电脑同时开启自动审批、OA 服务器

**设备授权**:
允许一台电脑保存审批所需 OA 凭据和可选飞书机器人密钥；凭据通过一次性迁移码加密转移并落入本机操作系统凭据库。
_Avoid_: 明文同步、普通配置同步、共享长期迁移码

**自动审批标记**:
写入 OA 审批意见的自动操作标识，包括自动通过或驳回、规则版本、简短审计编号，以及自动驳回时的原因和次数。
_Avoid_: 无标识审批意见、完整案件数据

**自动审批记录**:
办公助手保存的审批元数据，包括案件标识、OA 提交时间、审批时间、设备、动作、规则版本、原因和结果。
_Avoid_: OA 案件档案、审批意见全文

**暂停自动审批**:
审批值守继续保持登录和显示状态，但停止一切自动通过与自动驳回写入，直到审批人恢复。
_Avoid_: 退出登录、停止监测

**直接自动审批**:
审批人开启开关后不经过影子期，值守端对后续审批批次直接写入通过或驳回结果；技术异常除外。
_Avoid_: 观察期、仅模拟、等待人工逐案确认

**利冲检索**:
检查新案件当事人与律所既有案件是否存在对立关系的风险识别过程；命中结果是人工判断线索，不是最终法律结论。
_Avoid_: 利益冲突结论

**明确利冲**:
同一主体身份、案件对立方向和相关案件仍在办理三项均得到确认的利冲；主体身份应以身份证号或统一社会信用代码等可靠标识确认。
_Avoid_: 仅姓名相同、模糊命中

**姓名命中**:
不同案件出现相同或规范化后相同的当事人姓名，是需要人工复核的利冲线索，不能单独触发自动驳回。
_Avoid_: 明确利冲

**案由**:
民事案件使用的规范法律分类，应从 OA 认可的案由体系中确定。
_Avoid_: 案件描述、自由文本案由

**罪名**:
刑事案件使用的规范法律分类，应从 OA 认可的罪名体系中确定。
_Avoid_: 案由、案件描述

**收费方案**:
说明案件收费结构和计算方式的约定；在风险代理案件中，它是审批人审查收费合规性的主要依据。
_Avoid_: 收费金额

**低收费审查**:
对收费低于律所审批门槛的案件进行的特别说明审查。

**风险代理**:
收费结果与案件结果相关联的收费方式，需要审查适用范围、条款内容和最高收费限制。

**风险代理条款审查**:
审查 OA 记载的风险代理条款、收费金额、书面合同登记依据和风险告知登记依据；缺失、冲突或超过收费上限时自动驳回补正。
_Avoid_: 合同真实性认定、口头确认替代登记依据

**条款明确不合规**:
条款能够被可靠理解，且明确命中禁止适用情形、不合理权利限制或收费上限等规则；可以触发自动驳回。
_Avoid_: 条款表述复杂、机器不可判定

**条款信息不完整**:
风险代理条款缺少收费基数、比例、固定金额或计算方式等必要信息，无法完成合规计算；可以触发自动驳回并要求补充。
_Avoid_: 机器解析失败

**条款不可判定**:
条款已经填写，但其表述超出系统能够可靠解释的范围；必须转人工审批，不能作为违规结论。
_Avoid_: 条款明确不合规、条款信息不完整

**OA 文书**:
基于 OA 案件信息生成并归属于具体案件的法律文书。
_Avoid_: 本机材料、证据整理文件
