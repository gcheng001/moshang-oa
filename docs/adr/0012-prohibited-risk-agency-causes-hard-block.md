# 禁止风险代理案件按结构化确定命中自动驳回

司发通〔2021〕87号第（四）项禁止刑事、行政、国家赔偿、群体性诉讼、婚姻继承，以及社保待遇、低保、赡养费、抚养费、扶养费、抚恤金、救济金、工伤赔偿、劳动报酬案件实行或变相实行风险代理。此类命中没有裁量空间，因此风险代理案件的禁止范围审查分两层：案件基础类别（刑事/行政/赔偿）或已命中 OA 案由字典的规范案由及其层级路径落入禁止范围为确定命中，进入硬阻断自动驳回，人工审批勾选复核也不能放行；案情摘要等自由文本的关键词命中以及劳动争议分支下未确定含劳动报酬请求的案由只作线索转人工。变相风险代理（收费方式未登记为风险代理但方案约定按结果付费）不做自动识别，留给人工。这样选择用案由字典的结构化判断换取低误报的自动驳回，代价是禁止清单须随案由库和收费新规维护。
