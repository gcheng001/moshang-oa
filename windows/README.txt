办公助手（摩尚OA）Windows 便携版
=================================

【使用方法 A：从 GitHub 获取（推荐）】
1. 浏览器登录 GitHub 打开本仓库 → 绿色 Code 按钮 → Download ZIP（或 git clone）
2. 解压到任意位置（建议 D:\ 或桌面，路径里不要带特殊符号）
3. 进入 windows 文件夹，双击 install.bat 完成一次性安装（自动下载内嵌 Python
   和依赖，走国内镜像，约 1-3 分钟，装完窗口会提示"安装成功"）
4. 以后每次使用：双击 windows\start.bat 启动
5. 首次启动会弹出登录页，输入自己的 Agent API Key，勾选"记住"后下次自动登录
6. 关闭窗口即退出（后台程序会一并结束）

【使用方法 B：Mac 打好的 MoshangOA-Win 压缩包】
1. 解压后直接双击 start.bat（无需 install.bat，Python 已内置）
2. 其余同上

【功能】
- 案件看板：全所/我的案件、搜索筛选、案件详情
- 文书下载：案件详情抽屉底部 → 勾选模板下载，保存到 桌面\文书下载\{案号}\
  （委托人为法人时自动附带《法定代表身份证明书》）
- 案件审批：立案待审的合规检查（完整性/案由规范性/利冲/重复立案/收费）→ 通过/驳回
- 办案助手（材料转换/录屏取证/证据整理）依赖 macOS 工具链，Windows 版暂不可用

【环境要求】
- Windows 10 / 11（64位），系统自带 Microsoft Edge 即可，无需安装任何东西
- 能访问律所 OA（moshang2.ycq6.com）的网络

【常见问题】
- 启动出错：start.bat 的黑色控制台会显示报错并停住，把它和 logs\moshang_win.log
  （GitHub 方式在 windows\logs\ 下）截图发给管理员
- 提示"后端启动超时"：可能 8017 端口被占用，重启电脑或结束残留的 python.exe 进程再试
- 未安装 Edge 的电脑：会退回默认浏览器打开，功能一样，但关浏览器后后台程序不会自动退出，
  需关闭 start.bat 的控制台窗口或在任务管理器结束 python.exe
- 下载的文书在哪：我的桌面 → 文书下载 文件夹（若桌面被 OneDrive 接管，则在
  C:\Users\<用户名>\Desktop\文书下载）

【版本】
打包日期见压缩包文件名。与 macOS 版同源同功能（除办案助手外）。
